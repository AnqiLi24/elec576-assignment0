# ELEC 576 / COMP 576 (Fall 2026) – Assignment 0

Environment-setup assignment: Anaconda, IPython, NumPy/SciPy, Matplotlib,
Git/GitHub and an IDE. Everything in the submitted report is generated by
the scripts in this repository.

## Layout

| Path | Purpose |
|------|---------|
| `environment.yml` | conda environment `elec576` (Python 3.12, NumPy, SciPy, Matplotlib, IPython) |
| `scripts/task2_linear_algebra.py` | every row of the "Linear algebra equivalents" table from *NumPy for MATLAB users*, one command per line |
| `scripts/task3_plot.py` | the plotting script given in the assignment |
| `scripts/task4_plot.py` | a four-panel Matplotlib figure of my choice |
| `scripts/run_ipython.py` | types a command file into a real IPython session and saves the transcript with its `In [n]:` / `Out[n]:` prompts |
| `report/` | LaTeX source, transcripts, figures and the compiled PDF report |

## Reproduce

```bash
conda env create -f environment.yml
conda activate elec576          # conda info then reports "active environment : elec576"
conda info > report/task1_conda_info.txt
cd report
python ../scripts/run_ipython.py ../scripts/task2_linear_algebra.py task2_transcript.txt
python ../scripts/run_ipython.py ../scripts/task3_plot.py task3_transcript.txt
python ../scripts/run_ipython.py ../scripts/task4_plot.py task4_transcript.txt
tectonic report.tex        # or pdflatex report.tex
```
