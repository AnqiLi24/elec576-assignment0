\section{Transition from MATLAB to Python}
\subsection*{Task 2: the ``Linear Algebra Equivalents'' table in IPython}
Every row of the ``Linear algebra equivalents'' table of
\href{https://numpy.org/doc/stable/user/numpy-for-matlab-users.html}{NumPy for MATLAB users}
was run in IPython. The matrices used are
$a$, a $3\times 3$ non-singular matrix, for the linear-algebra rows;
$m$, a $21\times 9$ matrix, for the row-slicing rows that need at least
21 rows and 9 columns; a length-3 vector $v$ and a $2\times 3$ matrix $u$
with entries around 0.5 for the comparison rows; two $2\times 2$ blocks
$p$ and $q$ for the block and concatenation rows; and a symmetric
positive-definite \texttt{spd} for Cholesky, generalised eigenvalues and
conjugate gradients. Two entries of the table needed a small correction to
run on current SciPy: \texttt{signal.resample} requires an integer number
of samples, so \texttt{np.ceil(...)} is wrapped in \texttt{int(...)}, and
the closing parenthesis missing from \texttt{np.ix\_(np.r\_[0:9.],np.r\_[0:6.]}
was added.
